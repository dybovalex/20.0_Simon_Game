# Simon Game

A simple implementation of the classic Simon memory game built with HTML, CSS and JavaScript.

## How to Play

1. Open `index.html` in your web browser.
2. Press any key to start the game and watch the sequence of flashing colors.
3. Repeat the sequence by clicking the colored buttons in the same order.
4. The sequence gets longer each round. Try to remember as much as you can!

Have fun!
